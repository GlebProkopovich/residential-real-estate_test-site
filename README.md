# ЖК «Северный Сад» — Тестовый сайт жилого комплекса

Демонстрационный SPA-сайт жилого комплекса бизнес-класса в Москве. Предназначен для проведения тестовых заданий сотрудникам — полностью рабочий фронтенд без бэкенда.

## О проекте

**ЖК «Северный Сад»** — вымышленный жилой комплекс класса «Бизнес+» в районе Хорошёво-Мнёвники (Москва). На сайте представлены 12 квартир в трёх корпусах с фильтрацией, детальными карточками и формами обратной связи.

## Быстрый старт

### Локальный запуск

Сайт — статический SPA на vanilla JavaScript (ES-модули). Для локального просмотра нужен HTTP-сервер:

```bash
# Python
python -m http.server 8080

# Node.js (npx)
npx serve .

# PHP
php -S localhost:8080
```

Откройте `http://localhost:8080` в браузере.

### Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите содержимое проекта.
2. Перейдите в **Settings → Pages**.
3. В разделе **Source** выберите ветку `main` (или `master`) и папку `/ (root)`.
4. Сохраните — сайт будет доступен по адресу `https://<username>.github.io/<repo-name>/`.

> **Важно:** Маршрутизация построена на hash-based routing (`#/`, `#/apartments` и т.д.), поэтому дополнительная настройка SPA redirect не требуется.

## Техническая реализация

### SPA (Single Page Application)

Приложение реализовано как SPA на **vanilla JavaScript** с ES-модулями:

- **Роутер** (`js/app.js`) — hash-based маршрутизация через `window.location.hash`.
- При смене маршрута динамически подменяется только содержимое `#app`, без перезагрузки HTML.
- Модальные окна (формы) рендерятся один раз в `#modal-root` и переиспользуются.

#### Маршруты

| URL hash | Страница | Модуль |
|----------|----------|--------|
| `#/` | Главная | `pages/home.js` |
| `#/apartments` | Каталог квартир | `pages/apartments.js` |
| `#/apartment/:id` | Страница квартиры | `pages/apartmentDetail.js` |
| `#/contacts` | Контакты | `pages/contacts.js` |

### Компоненты

#### Header (`js/components/header.js`)

- Логотип и название ЖК
- Навигационное меню (Главная, Квартиры, Контакты)
- Номер телефона
- Кнопка «Обратный звонок» → открывает модальное окно callback-формы
- Адаптивное бургер-меню на мобильных устройствах

#### Footer (`js/components/footer.js`)

- Описание ЖК
- Контактные данные: телефон, email, адрес, режим работы, метро
- Навигационные ссылки

#### CallbackForm (`js/components/callbackForm.js`)

**Отдельный компонент** для заявок на обратный звонок:

- Секция перед подвалом на каждой странице (`renderCallbackFormSection`)
- Модальное окно из шапки (`renderCallbackModal`)
- Поля: имя, телефон, удобное время
- Валидация на клиенте
- При отправке данные логируются в `console.log` с типом `callback`

#### BookingForm (`js/components/bookingForm.js`)

**Отдельный компонент** для бронирования квартиры:

- Модальное окно, вызывается кнопкой «Забронировать» на странице квартиры
- Поля: имя, телефон, email, комментарий, чекбокс «Интересует ипотека»
- Скрытое поле `apartmentId` — ID бронируемой квартиры
- При отправке данные логируются в `console.log` с типом `booking`

> Формы callback и booking — **разные компоненты** с разной структурой полей и типом заявки, что позволяет подключать к ним разный бэкенд-функционал.

### Страницы

#### Главная (`pages/home.js`)

- Hero-блок с изображением проекта
- Генеральный план (интерактивные корпуса → переход в каталог с фильтром по корпусу)
- Блок преимуществ ЖК (6 карточек)
- Форма обратного звонка

#### Каталог квартир (`pages/apartments.js`)

- **Фильтры:** комнатность, корпус, этаж (от/до), цена (от/до)
- **Сортировка:** цена ↑↓, площадь ↑↓
- Карточки квартир с планировкой (SVG), ценой, этажом
- Фильтрация и сортировка работают на клиенте в реальном времени
- Клик по карточке → страница квартиры

#### Страница квартиры (`pages/apartmentDetail.js`)

- SVG-планировка
- Характеристики: номер, корпус, этаж, комнаты, площадь, цена
- Теги особенностей (балкон, вид, white box и т.д.)
- Кнопка «Забронировать» → форма бронирования
- Блок преимуществ конкретной квартиры

#### Контакты (`pages/contacts.js`)

- Контактная информация офиса продаж
- Карта-заглушка с координатами и ссылкой на Яндекс.Карты

### Данные (`js/data/complex.js`)

- `COMPLEX` — информация о жилом комплексе
- `APARTMENTS` — массив из 12 квартир
- Вспомогательные функции: `formatPrice`, `getApartmentById`, `getRoomLabel`, `getApartmentAdvantages`

### Стили (`css/styles.css`)

- Пастельная цветовая палитра (sage, cream, blush, lavender)
- CSS-переменные для цветов, теней, радиусов
- Шрифты: Montserrat (текст), Playfair Display (заголовки)
- Адаптивная вёрстка: breakpoints 992px, 768px, 480px

## Тестирование функционала

Для проверки работы форм откройте DevTools → Console:

1. **Обратный звонок** — отправьте форму, в консоли появится объект с `type: "callback"`.
2. **Бронирование** — на странице квартиры нажмите «Забронировать», отправьте форму, в консоли появится объект с `type: "booking"` и `apartmentId`.

## Зависимости

Проект не требует сборки и npm-зависимостей. Единственная внешняя зависимость — Google Fonts (подключается через CDN в `index.html`).
